# FOUNDRY Final Presentation

This directory contains the self-contained HTML slide deck for the FOUNDRY
final presentation.

## Format

- Opening cover (not counted)
- 12 content slides
- Closing and demo transition (not counted)
- Approximately 12 minutes of slides
- Approximately 8 minutes of live demo

## Speaker allocation

- Slides 1–3: Will Sun
- Slides 4–6: Alan Shen
- Slides 7–9: Jason Xiao
- Slides 10–12: Zhiheng Li
- Demo: two minutes per presenter

## Run locally

Open `index.html` in a modern browser, or serve this directory with any local
HTTP server:

```bash
cd presentation
python3 -m http.server 4173
```

Then open <http://127.0.0.1:4173/>.

## Controls

- Next: Right Arrow, Page Down, or Space
- Previous: Left Arrow or Page Up
- Opening / closing: Home / End
- Speaker notes: N
- Fullscreen: F
- Help: ?

The deck has no package installation or network requirement.
